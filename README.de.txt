Verwandle dein Shelly Wall Display in ein smartes Bedienpanel fuer dein Zuhause, angetrieben von Homey. Die App betreibt einen lokalen Server direkt auf deinem Homey und liefert ein touch-optimiertes Dashboard mit Echtzeit-Geraetesteuerung, Sensorwerten, einem animierten Energiefluss-Diagramm, Flow-Schnellstart-Buttons, Kamera-Schnappschuessen und PIN-geschuetzter Alarmverwaltung.

Geraete werden nach Raum geordnet oder als flache Liste angezeigt. Raumtitel antippen klappt Kacheln ein oder aus. Antippen zum Schalten, Schieberegler zum Dimmen, per langem Druecken Kacheln per Drag & Drop neu anordnen. Homey Flows lassen sich als Kacheln einblenden und mit einem Tipp direkt ausfuehren – optional mit Bestaetigungsdialog.

Dark Mode, vollstaendig anpassbare Design-Einstellungen (Kachelbreite, Kachelhoehe, Schriftgroesse, Akzentfarbe, Titel, Kachelform) und ein integriertes Energie-Dashboard machen es zu einem vollwertigen Smart-Home-Wandpanel. Gerätekacheln zeigen Werte, Status und Name einheitlich unten ausgerichtet.

Antippen einer Speaker-Kachel oeffnet den Mediaplayer – Albumcover, Titelinfo, Lautstaerkeregler und Transportsteuerung. Nach einer einstellbaren Leerlaufzeit fuellt das Albumcover den Bildschirm mit Ken-Burns-Zoom; das Cover direkt antippen springt sofort ins Vollbild.

Display-Profile ermoeglichen es, fuer jedes Shelly Wall Display individuell festzulegen, welche Geraete und Flows angezeigt werden. Ein Standard-Profil gilt fuer alle Displays. IP-spezifische Profile schraenken einzelne Displays auf ausgewaehlte Geraete und Flows ein – ideal fuer Mehrraum- oder Mehrgeraete-Setups.
